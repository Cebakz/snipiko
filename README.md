# Snipiko — browser playtest

Play: https://cebakz.github.io/snipiko/

Draw rectangles that match one number, clear rows and columns, and build combos.

This repository contains the deployable browser build. Extra hints and one continue per game are free in this playtest. No AdMob ads are shown in the browser. Progress and play history stay on the player's device/browser. Settings includes a play-history export for voluntary feedback.

This is a prototype for testing, not the Android/iOS store release.
